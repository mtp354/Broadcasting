# Withdrawn convergence assets

These three assets were active at baseline commit `5498dc4` and are retained only as historical review evidence. Their names preserve the original `figures/` or `manuscript/` origin.

The configuration fixed `seed=0`, which overrode the varying backend seed. Supposedly independent repetitions therefore reused the same random realization; the multi-seed uncertainty and associated evidence are unsupported. These assets are withdrawn from manuscript use and default figure generation.

No replacement convergence measurements were collected during the pre-data correction. Future collection must set each effective seed and trajectory count explicitly and archive the measurements before a replacement figure can be reviewed. Other historical convergence assets have not been attributed this specific defect and remain unchanged.
